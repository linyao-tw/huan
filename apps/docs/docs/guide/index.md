# HUAN 是什麼

HUAN 讙是一套跨平台、雲端管理的數位看板系統。

你在瀏覽器裡上傳影片與圖片、把畫面切成幾塊、放上文字與跑馬燈、安排星期一到星期五早上播哪一版，然後發布。現場的播放裝置會自己把需要的檔案下載下來、驗證雜湊、等全部就緒之後才切換到新版本。

## 它解決什麼問題

一般的數位看板系統有兩種常見做法，兩種都有明顯的痛點。

**串流播放**：畫面即時從伺服器拉內容。網路一斷就是黑畫面，而現場的網路往往是整棟建築裡最不可靠的一環。

**手動更新**：有人拿隨身碟到每一台機器前面換檔案。裝置一多就不可能維持一致。

HUAN 選了第三條路：**中央管理、本機播放**。內容在雲端編排，但實際播放的檔案存在裝置本機。網路只負責把「該播什麼」這件事同步過去。

## 它由什麼組成

| 元件           | 說明                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| **Admin**      | React 單頁應用程式。官網、登入、素材庫、版面編輯器、排程與裝置管理。     |
| **Server**     | Fastify。REST API、WebSocket 控制通道、簽章網址與稽核紀錄。              |
| **Worker**     | 獨立的 FFmpeg 程序。以 PostgreSQL 為工作佇列，負責轉檔、縮圖與素材回收。 |
| **Device**     | Electron 播放器。配對、同步、驗證、離線播放與排程執行。                  |
| **PostgreSQL** | 唯一的資料庫，同時也是工作佇列。                                         |
| **RustFS**     | S3 相容物件儲存。**暫存**用，不是永久素材庫。                            |

## 支援平台

播放裝置支援：

- Raspberry Pi OS 64-bit（arm64，建議 Pi 4 以上、4GB）
- Ubuntu（x64、arm64）
- Windows（x64、arm64）
- macOS（x64、arm64）

後台是網頁，任何現代瀏覽器都可以使用。
